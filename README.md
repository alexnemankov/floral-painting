# Floral Painting (Botanical Foliage & Sun Study)

Generative watercolor and botanical artwork created with p5.js and p5.brush.

### Features
- **Generative Landscape & Flora**: Unique procedural sky bands, watercolor sun discs, and intricate multi-layered botanical foliage.
- **Interactive**: Click anywhere on the canvas to generate a new piece.
- **High-Quality Export**: Click the bottom-left button to download a high-resolution PNG with a delicate sprout flourish animation.
- **Clean Mode**: Press `H` to toggle the UI / save button visibility.
